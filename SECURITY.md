# Security Policy

## Core Principles

1. Least privilege by default.
2. No long-lived AWS credentials in GitHub.
3. No secrets committed to source control.
4. Encryption enabled for sensitive data.
5. Logging enabled before production workloads are deployed.
6. Infrastructure changes are performed through Terraform.
7. Security findings must be investigated and documented.
8. Every remediation must be verified.
9. Production-style controls must be reproducible.
10. Evidence must never expose secrets or sensitive credentials.
